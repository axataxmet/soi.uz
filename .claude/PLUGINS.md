# Локальные плагины-скиллы

Этот каталог `.claude/` держит внешние плагины, которые не идут в git
(см. `.gitignore` — `.claude/skills/`). После клонирования репозитория
их нужно поставить заново.

## ui-ux-pro-max-skill

- Источник: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill (MIT)
- Что даёт: 7 скиллов дизайн-справочника — стили, палитры, шрифтовые пары,
  графики, гайдлайны по доступности, генератор дизайн-токенов, поиск компонентов
  shadcn/ui. Загружаются автоматически при следующем запуске Claude Code —
  новые скиллы подхватываются на старте сессии, не в текущей.
- Установлено: 07.08.2026, вручную (командной строки `claude`/`/plugin` в этой
  среде нет — desktop-хост без интерактивного терминала).

Переустановить:

```bash
git clone --depth 1 https://github.com/nextlevelbuilder/ui-ux-pro-max-skill.git /tmp/uupm
cp -R /tmp/uupm/.claude/skills/. .claude/skills/
rm -rf /tmp/uupm
```

Перед повторной установкой стоит свериться с апстримом — версия могла
измениться, а проверку на подозрительный код (`subprocess`, сетевые вызовы)
имеет смысл повторить.
